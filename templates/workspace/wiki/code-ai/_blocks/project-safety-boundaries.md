# Block：项目安全边界

> 类型：项目级通用约束 · 适用：所有角色与所有变更
> 本块只给通用下限；项目可以加严，不得放宽。

## 凭据与敏感数据

- 不读取、不复制、不写入真实密钥、令牌、口令、私钥或会话凭据。
- 不把真实个人数据、客户数据、内网地址、生产连接串写入文档、代码、日志、测试夹具或提交信息。
- 需要示例时使用显式假值，如 `<REDACTED>`、`example.invalid`，并保持可识别为占位符。
- 日志、异常、诊断与截图在输出前必须脱敏；不确定是否敏感时按敏感处理。
- 不在命令行参数、环境变量示例或错误信息中暴露秘密；发现已泄露的凭据立即停止并上报。

## 不可逆与高风险操作

以下操作默认禁止，除非取得明确、可追溯的授权，并已给出影响面、回滚方案与验证方式：

- 生产环境写入、删除、批量更新或配置变更；
- 真实资金、真实订单、真实支付或计费动作；
- 数据库结构迁移、数据回填、历史数据修复；
- 权限、角色、访问控制的放宽；
- 对外发布、部署、推送或通知真实用户；
- 覆盖或删除他人未提交的工作。

取得授权不等于可以省略回滚方案；无法回滚时必须在执行前明确说清并再次确认。

## Agent 输出不是权威

- 子代理的结论、记忆与推测只是输入，不是项目事实。
- 契约以项目权威文档与代码事实为准；文档冲突时停止并升级。
- 不得用“之前某次对话”或“模型认为”作为依据。
- 生成的代码、文档与建议在被验证前都只是候选。

## 最小权限与最小改动

- 只访问任务需要的文件与系统。
- 只改任务需要的范围；不顺手重构、不扩大写入范围。
- 不修改他人 owner 的权威文件；跨 owner 改动必须获得确认。
- 不新增长期有效的宽权限开关、后门或调试入口。

## 停止条件

出现以下任一情况，立即停止并交接：无法判定是否涉及生产、无法脱敏、授权不明确、回滚不可行、发现凭据泄露、需要越过写入边界。
