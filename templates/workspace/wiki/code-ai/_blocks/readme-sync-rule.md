# Block：README 同步

> 类型：项目级通用约束 · 适用：所有 Markdown 文档目录与入口页

## 原则

README 是目录的入口与导航契约。新增、移动或删除文档后，README 必须仍然能带读者走到每一份有效文档；否则文档等于不存在。

## 必须更新 README 的情形

- 新增、删除、重命名 Markdown 文件或子目录；
- 目录职责、阅读顺序或入口结构变化；
- owner、角色或 profile 列表变化；
- 权威文档位置、工程事实或命令入口变化；
- 文档被标记过期、拆分或合并。

## 链接规则

1. 使用标准相对 Markdown 链接，不使用 wiki 双链语法、HTML 导航或引用式链接。
2. 链接目标必须真实存在；不链接目录中不存在的占位文件。
3. 新增文档必须在同一次变更中从某个 README 可达，路径深度不超过项目约定上限。
4. 删除或移动文件时，同步修复所有指向它的链接，不能留下死链。
5. 链接文字应说明目标用途，禁止“点这里”式无信息标签。
6. 不链接被排除的临时工作区或未纳入扫描的目录。

## 内容边界

- README 只做入口与规则摘要，不复制子文档正文。
- 不写易变状态、进行中的任务、人员分工或临时结论。
- 命令、路径与事实必须来自可验证来源，不手写猜测。
- 目录职责变化时，先改 README 再改子文档，避免读者先看到孤儿文件。

## 自检

- [ ] 目录内每个 Markdown 文件都能从入口在约定深度内到达。
- [ ] 没有死链、没有指向已删除文件的链接。
- [ ] 新增文件已登记，删除文件已清理引用。
- [ ] README 没有变成第二份权威正文。
