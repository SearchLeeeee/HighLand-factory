# Block：Agent 记录

> 类型：项目级通用约束 · 适用：所有 owner profile 与子代理会话

## 记录头（固定五字段）

每条 agent 记录必须以下列五字段开头，顺序不变，字段名不改：

- **Role**：执行角色（阅读 / 实现 / 评审 / 验证）与所属 owner。
- **Edit when**：本记录何时必须更新，以及更新责任人。
- **Impact**：影响面（文件、契约、数据、权限、其他 owner）。
- **Verify**：如何验证记录仍然准确（测试、评审、对照权威文档）。
- **Sync**：需要同步的文档、manifest 或 profile。

五字段缺一，记录视为无效。

## 记录规则

1. 记录写在项目约定的 agent 记录位置；不得把记录塞进稳定契约文档冒充权威。
2. 一次变更对应一条记录；不要把多个无关变更混进同一条。
3. 记录只写事实与证据，不写猜测、情绪或“应该没问题”。
4. 记录不得包含真实凭据、个人数据、生产地址或客户信息。
5. 记录与权威文档冲突时，以权威文档为准并修正记录，不得让记录反过来覆盖契约。
6. 记录不是决定：需要改变契约时走评审与文档同步流程，不能只留一条笔记。
7. 过期记录要标注失效日期与原因，不能静默删除他人记录。

## Edit when 的典型触发

- 角色职责、写入范围或升级路径变化；
- 发现新的稳定事实或纠正错误事实；
- 评审结论、阻断项或后续项变化；
- 约束块、manifest 或 profile 组合变化；
- 项目进入新阶段，旧假设不再成立。

## 自检

- [ ] 五字段齐全且具体。
- [ ] 影响面与同步项可执行，不是空话。
- [ ] 没有把记录当成决策或权威。
- [ ] 敏感信息已排除。
