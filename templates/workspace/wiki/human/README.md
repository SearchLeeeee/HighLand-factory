# Human

本目录是人类的接手入口：用最少的篇幅说明系统目标、当前边界和阅读顺序。它不承载
业务规则，规则见[文件权威地图](../02-file-authority-map.md)指定的文档。

## 阅读顺序

1. [系统总览](system-overview.md)：一页纸理解系统做什么、不做什么。
2. [当前决策](../03-current-decisions.md)：当前有效的跨领域规则。
3. [文件权威地图](../02-file-authority-map.md)：冲突时听谁的。
4. [Wiki 根 MOC](../README.md)：按主题继续深入。

## 维护

- 新文档随项目推进逐步加入，并在本文件登记一行「链接 + 一句角色说明」。
- 只写导航与角色说明，不复制总览或决策的正文。
