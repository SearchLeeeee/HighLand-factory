# Features

本目录存放已经稳定、需要独立入口的 Feature 说明：边界、行为、验收结论。

## 文档

- 初始阶段不预置子文档。新文档随项目推进逐步加入，每个条目一行：「链接 + 一句
  角色说明」。
- 仍在讨论或未验收的需求**不写在这里**，只留在 `wiki/feature-workspace/`；验收
  通过并合并后才提炼为本目录的稳定说明。
- 本目录的文档可以引用 I/F 编号用于追溯，但不得反向链接临时工作区中的路径。
