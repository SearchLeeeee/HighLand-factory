# Governance

本目录是边界、文档维护协议和流程门禁说明的长期权威：什么允许、什么禁止、由谁
授权。

## 文档

- [Workflow Profile](workflow-profile.md)：当前 owner、命令、验证要求、门禁与安全
  摘要。**由工具生成，禁止手工编辑**，权威仍是 `.factory/factory.yaml`。
- [初始化记录](init-record.md)：`factory init` 写入的 provenance 基线；由工具重建，
  只作历史证据。
- 其余文档随项目推进逐步加入：边界规则、文档变更协议、仓库形态规则等。每个条目
  一行「链接 + 一句角色说明」。
- 初始阶段除生成文件外不预置子文档。

冲突裁决见[文件权威地图](../02-file-authority-map.md)；导航入口见[Wiki 根 MOC](../README.md)。
