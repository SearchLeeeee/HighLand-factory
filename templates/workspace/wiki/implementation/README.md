# Implementation

本目录是后端、前端、共享契约和专题实现的长期权威：接口长什么样、字段什么含义、
失败怎么处理、如何观测。

## 文档

- 初始阶段不预置子文档。新文档随项目推进逐步加入，每个条目一行：「链接 + 一句
  角色说明」。
- 建议按 `backend/`、`frontend/`、`shared/` 和专题子目录组织；只在确有内容时创建。
- 契约变更必须与代码同一次提交，并回链到受影响的测试与验证记录。

冲突裁决见[文件权威地图](../02-file-authority-map.md)；导航入口见[Wiki 根 MOC](../README.md)。
