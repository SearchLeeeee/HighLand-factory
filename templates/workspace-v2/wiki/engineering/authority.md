# 权威来源与冲突处理

| 问题 | 首要来源 |
| --- | --- |
| 用户目标、业务行为、范围、当前决策 | [产品](../product/README.md)及其主题页 |
| 代码行为、接口、配置与测试 | 当前代码及其对应工程主题 |
| 命令、owner 与流程门禁 | 项目配置和[生成的摘要](workflow-profile.md) |
| 验证结论与限制 | {{layout.baseline_reference}}与相应验证主题 |
| 执行职责与写入范围 | [Code AI](../code-ai/README.md) 与任务 profile |
| 可复用的职责经验 | [类型索引](../by-type.md)中的对应角色页 |

冲突时核对当前实现、测试和决策依据，明确影响范围，由该事实的负责人裁决并同步受影响的引用。历史裁决通过 Git 与定向过程证据追溯。
